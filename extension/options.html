BanTheFake options

The BanTheFake site that scans your images, for example https://banthefake.your-domain.org. The default https://YOUR-DOMAIN.example is a placeholder: replace it with a real server before scanning. Only https:// addresses are accepted, except http://localhost and http://127.0.0.1 for development.

Privacy

An image is read and sent only when you right-click it and choose "Check with BanTheFake", and only to the server above. The extension has no analytics, loads no remote code, and keeps results in memory only until the browser closes.

When you save, your browser asks you to let the extension connect to this one server. That permission covers only the server's host. If you decline, scanning works only if the server lists this extension in BTF_CORS_ORIGINS.
